# PhenologyExperimentApp

Browser-based field apps for plant–pollinator experiments. They run on any phone or tablet browser; no installation needed.

| App | Purpose | Link |
|---|---|---|
| **PhenoTracker** | Flower phenology census per pot (buds, open flowers, senescent) | [Open](https://agostinatorresm.github.io/PhenologyExperimentApp/PhenoTracker/) |
| **BeeTracker** | Timing of bumblebee visits to flower species, with switches and visitation rate | [Open](https://agostinatorresm.github.io/PhenologyExperimentApp/BeeTracker/) |

## Data
The apps contain no data. Records are kept only in the user's browser and exported as CSV/TSV.
BeeTracker can optionally sync with a Google Sheet: paste your own Apps Script URL into `SHEET_URL` in `BeeTracker/index.html`.
